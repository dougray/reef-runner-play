# Reef Runner

**Play:** https://dougray.github.io/reef-runner-play/

A free cartoon pirate arcade game. Steer between storm clouds and sandbars, sink British
frigates and Spanish galleons, and take on HMS Invincible. It runs entirely on your device:
play in the browser, install it as an app, or download the single file and play offline.

This repository holds the **built** game that GitHub Pages serves:

- `index.html`: the landing page
- `play/`: the game (installable, works offline)
- `reef-runner.html`: the whole game in one file
