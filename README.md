# Reef Runner

**Play:** https://reefrunner.us/

A free cartoon pirate arcade game. Steer between storm clouds and sandbars, sink British
frigates and Spanish galleons, and take on HMS Invincible. It plays right in the browser and
runs entirely on your device.

This repository holds the **built** game that GitHub Pages serves:

- `index.html`: the landing page
- `play/`: the game
